# 大乐透 · 开奖与选号

一个可安装的中文渐进式 Web App（PWA），适配 Windows 桌面浏览器和 iPhone Safari。

## 已有功能

- 随项目导入的 `history.json`：源自用户提供的 `lotto-20261007.csv`，共 2,927 期，每期保留期号、前区 5 个号和后区 2 个号。
- 开奖记录：检索、手动录入、删除、CSV 导入和导出。
- 图表分析：号码频次、当前遗漏、近 30 期和值/奇偶分布，以及前后区号码矩阵。图表对应工作簿中的遗漏值图、指标图、前区旋转图、后区旋转图分析思路，由开奖号码重新计算。
- 开奖日历：展示每周一、周三、周六的常规开奖日；已录入 2026 年春节与国庆官方休市日期，可翻月查看并添加后续公告中的临时休市调整。自定义调整随 Supabase 账号同步。
- 随机选号：均匀随机选择 5 个前区号和 2 个后区号。
- 计算器：复式组合数和票面金额、与历史期号核对命中数和奖级；奖金金额请以官方当期公布为准。
- 本地数据默认保存在浏览器。配置 Supabase 后，以邮箱登录同步到其他设备。

## 本地预览

需要 Node.js：

```bash
npx serve .
```

在浏览器打开命令输出的地址。PWA 安装和 iPhone 添加到主屏幕需要 HTTPS（localhost 开发环境除外）。将整个目录部署到任意静态 HTTPS 托管后，在 Windows Edge/Chrome 选择“安装应用”；iPhone Safari 选择“添加到主屏幕”。

## 启用跨设备云同步

1. 创建 Supabase 项目，在 SQL Editor 执行 `supabase-schema.sql`。
2. 打开应用设置，填写项目 URL 与 anon/publishable key。不要输入 `service_role` 密钥。
3. 注册邮箱并按项目认证设置确认邮箱，再登录。另一设备打开同一个部署地址并使用同一账号登录。
4. 每次新增、删除、导入记录或修改休市日后会自动上传。登录时读取云端记录；同一账号同时在多台设备改数据时，最后一次同步会覆盖整份历史，请先在一台设备操作。

Supabase JS 通过浏览器从 esm.sh 加载；首次登录需联网。其余应用资源由 Service Worker 缓存，可离线查看已加载页面和数据。

## 规则与边界

开奖日规则：超级大乐透通常每周一、周三、周六开奖（休市日除外）。2026 年彩票市场休市安排依据[财政部公告](https://www.mof.gov.cn/gp/xxgkml/zhs/202512/t20251225_3980248.htm)，具体体彩销售和开奖调整依据[春节公告](https://www.lottery.gov.cn/xxgk/tzggz/20260113/10051945.html)和[国庆公告](https://www.sporttery.cn/jczx/ggtz/20260923/10055736.html)。App 将受影响的周一、周三、周六标成休市；其他年份或临时调整需在日历页添加。

依照提供的玩法介绍：基本投注为前区 01–35 选 5 个、后区 01–12 选 2 个，每注 2 元；追加每注加 1 元。`lotto-20261007.csv` 不含开奖日期，因此历史列表使用期号显示。中奖核对计算命中数和奖级，不自行估算浮动奖金、奖池或派奖。

日历为常规日期提示，未来官方休市日期需根据后续公告添加；开奖日期以体彩中心通知为准。历史频次、遗漏和和值图只呈现已录入数据，不能预测未来开奖结果，也不会改变随机中奖概率。请理性参与。
