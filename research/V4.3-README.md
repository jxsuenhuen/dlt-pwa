# V4.3 真实预测记录台

独立研究页面：`research/v4-ledger.html`。不修改 V15 主应用、授权系统或 Service Worker。

## 使用

1. 在 GitHub Pages 打开 `/dlt-pwa/research/v4-ledger.html`。
2. 页面读取仓库 `history.json`，输入**大于当前历史最新期号**的目标期号。
3. 选择预先固定的窗口（30/60/120/300），生成一注前区5个、后区2个号码。
4. 页面立即在当前浏览器 localStorage 保存期号、生成时间、窗口、号码及使用到的最后一期历史数据。
5. 开奖后选择对应期号，输入官方公布的前区和后区号码，保存命中结果。
6. 定期导出 JSON 备份；换浏览器或设备前先导出，之后可导入。

## 重要限制

- 此版本是本机记录原型，不是防篡改的第三方时间戳存证。localStorage 可被清除或修改，不能据此证明预测一定在开奖前生成。
- 页面不自动抓取或认证开奖结果；请对照官方开奖公告手动核对。
- 每期每个浏览器只允许通过界面封存一次；备份导入不会覆盖本机已有同一期记录。
- 频率加权模型只用于实验，不保证比随机选号更准确，也不构成投注建议。
- 本页面不接入 Supabase，不改变 V15 买家端、授权码或现有数据。
